# data/gazetteer — names to H3 cells

Built 18 Oct 2026 from Natural Earth 10m (admin-0, admin-1, rivers and lake centrelines,
lakes, populated places) plus a few hundred historical cities and ~850 historical regions
written down from knowledge. Resolver: `tools/gazetteer.py`. Builder: `tools/build_gazetteer.py`
(Natural Earth tables) and `tools/regions_src.py` (regions.jsonl).

All cells are **indices into `data/grid/land_r5.txt`** (line number, 0-based; 524,441 land
cells at H3 resolution 5, about 253 km² each), stored as runs in the anchors' convention:
`"start-end"` inclusive or a bare integer. `grid.from_runs` / `gazetteer.from_runs` expand them,
`Gazetteer.to_h3` turns indices into H3 strings.

## Using it

```python
import sys; sys.path.insert(0, "tools")
from gazetteer import Gazetteer, GazetteerError
g = Gazetteer()
cells = g.resolve({"region": "Khorasan"})      # set of land-grid indices (2,206 cells)
cells = g.resolve({"place": "Merv", "km": 100})
g.trace                                        # what the last resolve matched, one line per name
h3s = g.to_h3(cells)
```

```
python3 -I tools/gazetteer.py resolve '{"admin1": "Normandie", "country": "France"}'   # count, bbox, names matched
python3 -I tools/gazetteer.py resolve '{"region": "Deccan"}' --cells                   # also the runs
python3 -I tools/gazetteer.py check [--counts]     # resolve every regions.jsonl entry, list failures
python3 -I tools/gazetteer.py names khor           # search every name list for a string
```

Run the CLI from a scratch directory (never from a download directory); it takes ~1 s to load
the tables and ~80 s for a full `check`.

### Spec grammar

The grammar from `master-plan.md`, all forms implemented:

```
{"country": name}
{"admin1": name, "country": name}        name may also be an NE "region" value (Toscana, Siberian, Kanto)
{"place": name, "km": r}                 optional "country" to disambiguate (Tripoli, Victoria, Santiago)
{"lon": x, "lat": y, "km": r}
{"cliopatria": Name-or-slug, "year": y}  the polity's Cliopatria shape that year (tools/grid.py; anchors when the year is an anchor year)
{"region": name}                         an entry of regions.jsonl (specs nest; 20 levels max)
{"polygon": [[lon, lat], ...]}           at most 12 points; fallback only
{"border_band": {"a": slug, "b": slug, "year": y, "width": cells}}
{"union": [...]}, {"minus": [A, B, ...]} (A minus the rest), {"intersect": [...]}
```

Gazetteer extensions (not in the master plan; use them only through regions.jsonl so briefs stay
in the shared grammar): `{"river": name, "km": r}` (cells the river passes through, widened r km)
and `{"lake": name}`. Any spec may carry `"text"`, `"note"`, `"confidence"`; they are ignored.

### Matching rules

* Names are normalised (NFKD, accents and apostrophes dropped, hyphens/dots/commas to spaces,
  case-folded); a leading "the " and a parenthesised suffix are also tried. Every row's `name`
  and `alt_names` are indexed; a row whose own name is the key beats one that only has it as an
  alias (so "Great Lakes region" is the North American one, "Great Lakes (Africa)" the other).
* Countries: NE `ADMIN` name, NE short `NAME` ("Dem. Rep. Congo", "S. Sudan", "Bosnia and Herz.",
  "Fr. Polynesia"), ISO codes and common English/historical names ("Burma", "Persia", "Zaire",
  "Ivory Coast", "Czechia", "Turkey"/"Türkiye", "Swaziland") all work.
* admin1: the unit's own name, then NE's `region` field (unioned: `{"admin1": "Toscana", "country": "Italy"}`
  is the whole region, `"Siberian"` the whole federal district), then alt_names. The `country`
  filter accepts NE names and aliases; "found in: X" is printed when the name exists elsewhere.
* Places: exact name before alias, then larger population, then NE over knowledge rows; `"country"`
  restricts. Historical names are aliases: Constantinople, Reval, Bombay, Peking, Edo, Léopoldville...
* Failures raise `GazetteerError` naming the kind and the six closest names (difflib, cutoff 0.55).
  A bad Cliopatria slug lists the closest slugs; a year outside the polity's span lists its spans.

## Adding or changing a region

regions.jsonl is generated: edit `tools/regions_src.py` (helpers `C` country, `A`/`As` admin1,
`P` place disk, `U` union, `M` minus, `I` intersect, `R` region, `PG` polygon, then
`reg(name, alt_names, spec, confidence, note)`), run

```
python3 -I tools/regions_src.py          # rewrites data/gazetteer/regions.jsonl
python3 -I tools/gazetteer.py check      # every entry must resolve; the script refuses duplicate names
```

The generator keeps rows of regions.jsonl that it does not itself define, so a line appended by
hand survives a rerun (and must be deleted by hand). Prefer admin-1 unions over polygons, a
polygon over nothing; set confidence 1 when the extent is a guess, 3 when the region equals a
modern unit. Names of modern units follow Natural Earth spelling (`admin1.jsonl` `name` column;
`tools/gazetteer.py names <text>` finds them). Regions that are themselves modern units carry a
suffix to avoid clashing with country/admin1 names: "Prussia (region)", "Gujarat (region)",
"Cyprus (island)", "Macedonia (region)".

## Added on 1 Nov 2026 (Phase C unresolved names)

The Phase C compile left 565 names unresolved. The gazetteer run (`notes/phase-c/gazetteer-run-2026-11-01.md`)
added 361 places, 127 regions and 5 aliases (the Lachin district, see below) and left the rest listed in that note.

* **Places** are in `EXTRA_PLACES`, second block, one tuple per place with the Wikipedia page the coordinates came from; the
  rows in `places.jsonl` are the output of `python3 -I tools/build_gazetteer.py places`. A name that already belonged to
  another place keeps its old meaning when written without a country: "Kish" stays Kish (Iraq) and the island is `Kish Island`
  (alias "Kish", use `"country": "Iran"`); "Banda" stays Banda Neira and the Uttar Pradesh town is `Banda, Uttar Pradesh`
  (alias "Banda" with `"country": "India"`); "Old Oyo" stays Oyo-Ile; "Philadelphia" is the U.S. city unless `"country": "Turkey"`
  (Alasehir). Always give `"country"` for Moree (Ghana or Australia), Olbia (France, Italy, Ukraine), Banda, Kish, Patan.
* **Regions** were appended to `regions.jsonl` by hand (the generator keeps them). Where Natural Earth has a unit that is the
  region it was used (Kvarner = Primorsko-Goranska, Transdanubia = nine Hungarian counties, Southern Cameroons = Nord-Ouest + Sud-Ouest,
  Savinja = 17 Slovenian municipalities, Magna Graecia = Calabria + Basilicata + Apulia + Campania + Sicily). 106 rows are pure
  polygons and 11 more contain one: Greek peripheries, Ethiopian provinces, the Bantustans, the Duars and similar have no
  Natural Earth unit. Each `note` says whether a page was opened; "page not opened" means the extent comes from the modern map
  and has not been checked against a source. Confidence 1 (39 rows) is a guess at the extent, 2 a composite of modern units that
  is close, 3 a region equal to a modern unit.
* **Aliases.** The admin-1 row Natural Earth calls "Lankaran" (6 cells, 39.5-39.9 N 46.1-46.5 E, ISO code AZ-LAN, region field
  "Kalbajar-Lachin") is the Lachin district: it carries the aliases Laçın, Lacin, Lachin, Lachin District, Lachin Rayon, so
  `{"admin1": "Laçın", "country": "Azerbaijan"}` resolves. Edited by hand in `admin1.jsonl`; a rebuild of admin1 drops it.
  `{"admin1": "Lankaran"}` still unions this row with the real Lankaran (8 cells, not 2).

## Known gaps and quirks

* Natural Earth files **Crimea and Sevastopol under Russia**; `{"admin1": "Crimea", "country": "Ukraine"}`
  fails with "found in: Russia". The "Crimea" region uses the Russian rows.
* Overseas parts are inside their country rows: Netherlands includes Bonaire/Saba/St. Eustatius
  (use region "European Netherlands"), France its overseas departments (region "Metropolitan
  France"), Spain the Canaries, Portugal Azores/Madeira, Norway Svalbard, Chile Easter Island,
  Ecuador Galápagos, USA Alaska/Hawaii, India the Andamans. `minus` them when it matters.
* NE spellings and typos are kept as names (aliases cover the usual ones): "Seien-et-Marne",
  "Zinguldak", "Kinkkale", "Crotene", "Oristrano", "Sjaælland", "Hasaka (Al Haksa)", "Homs (Hims)".
  Some NE `region` groupings are odd (Greek "Attiki" sits in region "Peloponnisos").
* 203 regions use polygons (86 before 1 Nov: mostly Chinese, Central Asian, steppe, desert and American
  frontier regions without modern units: Hexi Corridor, Tarim Basin, Ordos, Pontic Steppe, Sahel,
  Great Plains...; 117 added on 1 Nov, see above). Their edges are approximate; most carry confidence 1-2.
* Regions resolve to **present-day land cells**: a historical region's coastline, lakes and the
  Aral Sea are today's.
* Rivers are NE 10m centrelines: 1,053 named rivers, no tributaries below that scale; deltas and
  braided reaches are a single line. Lakes smaller than ~250 km² are one cell or none.
* Quneitra (Golan) is a sliver in NE admin-1; the "Golan" region is a polygon.
* Places from knowledge have no population and coordinates to ~0.05°; 46 NE places have no land
  cell (Antarctic stations, Diego Garcia, atolls).
* A `place` whose radius is below the grid spacing (~16 km) resolves to **nothing** when the point's own cell has its centre in
  the sea: `Gazetteer.disk` takes the land cells whose centre lies within km and falls back to the containing cell only if that
  is land. It ignores the row's `cell` (which `build_gazetteer.py` moves to the nearest land cell). Menton (4 km), Roquebrune-Cap-Martin
  (3), Akwidaa, Antibes, Aegina, Sorrento, Taba, Kish Island, Skiathos, Cobh, Erice, Preveza, Gramvousa, Tiran, Sanafir and
  Qit'at Jaradah are in `places.jsonl` with correct coordinates but resolve empty at the radii the dossiers ask. A fallback to the
  nearest land cell in `disk` fixes all of them (tested in scratch); that is a resolver change, not done here.
* Sub-grid and polar names that cannot resolve: Hawar Islands (51 km², 1.5 km off Qatar), Janan Island, Fasht ad Dibal,
  Swan Islands, Antarctica (no land cells in the grid: Australian Antarctic Territory, Ross Dependency).
* Natural Earth gives Morocco the part of Western Sahara west of the berm (Dakhla included): country "Western Sahara" has only 331 cells.
  "Tiris al-Gharbiyya" is therefore cut from both rows.
* Natural Earth was the only reachable source; Wikidata/OSM could not be used to verify names.
